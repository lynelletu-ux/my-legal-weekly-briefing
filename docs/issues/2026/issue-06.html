信号级别：工具治理级｜来源：Harvey AI｜发布日期：2026-09-14｜国内律师参考价值：高

核心内容：Harvey发布法律AI供应商评估清单，重点覆盖法律数据来源、客户数据保密、数据本地化、零数据留存（ZDR）、分包商和供应链、模型与产品更新后的政策变化，以及长期运行Agent的治理与问责。文章强调，采购方不能只看当前隐私承诺，还要看供应商在产品演进时如何披露变化并保持透明。

为什么值得律师看：这与律所实际采购AI工具直接相关。尤其在将客户材料、合同、证据或内部知识库接入第三方AI时，建议把数据留存、训练使用、分包商、跨境、日志、模型切换、异常事件通知写进采购尽调或内部AI使用规则，而不是只看“是否承诺不训练”。

可直接带走：法律AI采购尽调至少问六件事：数据从哪里来、客户材料是否用于训练、是否真正ZDR、分包商能看到什么、模型切换时政策是否变化、Agent长期任务如何审计与停止。

【Codex评分 7.2】未投保交强险：投保义务人与交通事故责任人的责任如何衔接

领域：侵权 / 机动车交通事故 / 保险｜来源：山东高法｜发布日期：2026-09-17｜地域：全国规则｜内容类型：入库案例｜时效标记：本周

核心内容：本期Feed收录的入库案例聚焦未依法投保交强险时，车辆投保义务人与实际交通事故责任人并非同一主体的责任承担。现行《民法典》侵权责任编司法解释（一）第二十一条已经把两类主体的责任关系进一步细化：交通事故责任人承担其作为侵权人应承担的全部责任，投保义务人在机动车强制保险责任限额范围内与交通事故责任人共同承担责任，同时避免被侵权人获得超过实际损失的重复赔偿。

可直接带走的规则：起诉未投保交强险案件时，不要只机械写“车主承担交强险限额责任”。应先区分登记车主/投保义务人与实际侵权人，再根据是否合并起诉、交强险限额内外以及追偿关系分别设计诉请和责任层次。

为什么值得我看：这类案件的难点不是“未投保就赔”这么简单，而是主体身份、限额内共同责任、限额外侵权责任及内部追偿的拆分。对诉请设计和判决主文理解都有迁移价值。

核验：Feed已取得山东高法微信原文直链；相关责任规则另由最高人民法院公开司法解释页面及山东法院官方案例页面交叉核验。

核心内容：报道显示，一场商事纠纷庭审结束后，承办法官继续前往建材存放现场核实情况，案件于次日以撤诉收尾。对律师更有价值的并非“撤诉”这一结果本身，而是庭审后的事实核实、争议焦点收缩以及对履行现状的现场确认如何推动争议实质化解。

可直接带走的规则：商事案件庭审结束并不意味着事实工作结束。若争点涉及货物、工程材料、现场履行状态或可恢复交易关系，可以提前准备现场清单、照片/视频、数量与权属说明，并在庭后补充核验阶段主动把争议压缩到可解决的问题。

为什么值得我看：它对庭后工作方式有迁移价值：庭审暴露出的事实缺口，应尽快转化为可核验事项，而不是只等判决。尤其是合同、货物、工程类案件，现场状态可能直接改变和解或撤诉空间。

【Codex评分 7.0】商标法时间效力、授权确权两份司法解释稿公开征求意见

领域：知识产权 / 商标 / 司法解释｜来源：中国应用法学 / 最高人民法院｜发布日期：2026-09-14—09.15｜地域：全国｜内容类型：司法解释征求意见｜时效标记：高

核心内容：最高人民法院就《适用〈中华人民共和国商标法〉时间效力的若干规定（征求意见稿）》以及修订后的商标授权确权行政案件司法解释稿公开征求意见。背景是新修订商标法将于2027年1月1日起施行，司法解释需要解决新旧法衔接及授权确权案件适用问题，征求意见截止至2026年10月28日。

可直接带走的规则：近期办理商标行政或民事争议时，应开始单独标记“行为发生时间—申请/审理时间—新法施行时间”，避免把实体规则变化与时间效力问题混在一起。对跨越2027年1月1日的案件尤其要预留新旧法衔接分析。

为什么值得我看：虽然不是当前核心办案领域，但属于明确的全国性规则变化信号。征求意见阶段不应当作现行裁判规则使用，但值得提前建立时间效力清单。

核验：最高人民法院官网已独立核验两份司法解释稿、发布时间、反馈方式及2026-10-28截止日期；同时保留Feed取得的中国应用法学微信原文。
