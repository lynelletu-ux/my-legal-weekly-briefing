一｜AI + 法律

【Web补充】最高法发布涉人工智能纠纷审理意见：AI侵权、训练数据、产品责任与证据规则首次形成系统司法指引

信号级别：格局级｜来源：最高人民法院｜发布日期：2026-09-07｜国内律师参考价值：高

核心内容：最高人民法院发布法发〔2026〕10号《关于依法审理涉人工智能纠纷案件的意见》，共5部分24条，明确涉AI侵权原则上依现行法律确定归责，并针对AI换脸拟声、隐私侵害、训练中处理公开个人信息、生成式AI服务提供者责任、AI产品责任、自动驾驶事故、知识产权、开源软件、技术合同、数据使用以及AI证据审查等问题提出裁判指引。最高法同时强调我国尚无专门人工智能法，本意见以民法典、个保法、著作权法、民诉法等现行法律为基础。

为什么值得律师看：这是本期最重要的重大遗漏补充。它把此前分散在人格权、个人信息、产品责任、知识产权和民事证据中的AI问题拉进同一司法框架。对实际办案尤其重要的是：今后涉及AI生成内容、训练数据、模型服务、自动驾驶、虚假AI证据时，诉请设计、归责路径、过错证明和证据真实性审查都会更有明确抓手。

【Codex评分 8.4】Ghost in the machine：律师使用生成式 AI，专业责任不会转移给机器

信号级别：应用落地级｜来源：Law Society of Ireland Gazette｜发布日期：2026-09-07｜国内律师参考价值：高

核心内容：爱尔兰律师协会刊文总结法律实践中的AI落地，并结合9月1日生效的高等法院 HC142 实务指示强调：法院允许并承认生成式AI可能提升效率、降低成本，但提交文件的人仍对文件内容承担全部责任，AI不会替代专业判断。文章进一步将律所工作拆成确定性自动化、AI辅助后人工批准、必须由律师作实质判断三类，并讨论 shadow AI、供应商评估、流程适用性和知识管理。

为什么值得律师看：最有价值的不是外国法院规则本身，而是工作流判断框架：并非所有任务都值得用AI。批量字段填充、标准文档组装等确定性任务往往传统自动化更安全；AI适合处理模糊信息和初步分析，但最终诉讼判断仍需律师承担。对搭建个人或团队AI工作系统，这是一套很实用的分工标准。

【Codex评分 8.2】iManage × Wordsmith：受治理的律所知识库开始直接连接 Agent 工作流

信号级别：应用落地级｜来源：Wordsmith AI / iManage｜发布日期：2026-09-02｜国内律师参考价值：高

核心内容：Wordsmith 与 iManage 宣布技术合作，把 iManage 中受权限和治理控制的文档、matter、人员与机构知识连接到 Wordsmith 的 agentic legal workflows。公开方案强调，AI可通过受支持API访问相关知识，用于起草、审阅、红线修改和日常法律问答，并计划在未来版本将工作成果回存至 iManage；“回存”仍属于后续计划，不应当作现有功能表述。

为什么值得律师看：这类架构与律师办案系统的方向高度一致：AI不应另起一座孤立知识库，而应在权限控制下直接读取现有案件和知识资产，并把工作成果重新进入原有系统。对案件材料、检索成果、模板、复盘和SOP的长期沉淀来说，“知识治理层 + Agent执行层”比单纯购买更强模型更值得关注。

【Codex评分 7.0】深圳法院发布2025年度仲裁司法审查典型案例：仲裁地、非对称争议解决条款与案外人不予执行审查

领域：商事仲裁 / 仲裁司法审查 / 程序｜来源：深圳市中级人民法院｜发布日期：2026-09-04｜地域：深圳｜内容类型：典型案例｜时效标记：本周

核心内容：深圳中院发布10件2025年度仲裁司法审查典型案例，覆盖确认仲裁协议效力、撤销仲裁裁决、案外人申请不予执行以及认可和执行香港仲裁裁决。案例涉及新仲裁法下“仲裁地”、非对称诉讼条款、瑕疵仲裁机构约定、深汕合作区仲裁机构确定、合伙企业简易注销后承诺人是否受仲裁条款约束、代位权人与仲裁协议效力、伪造签名以及仲裁员利益冲突等。

可直接带走的规则：一是新仲裁法下约定仲裁地但未约定机构，并不当然导致条款无效；二是合同一方享有诉讼选择权的非对称条款，不当然等同于“或裁或诉”，权利人明确选择仲裁后可形成有效仲裁合意；三是仲裁条款表述有瑕疵时，法院倾向结合当事人真实仲裁合意、地域及唯一仲裁机构等因素作有利于仲裁协议有效的解释。

为什么值得我看：它兼具深圳地域价值和高程序迁移价值。无论以后做服务合同、股权转让、建设工程或涉港商事案件，只要合同中存在仲裁条款，这组案例都能直接帮助判断管辖抗辩、仲裁协议效力、撤裁与不予执行的攻击路径。

可迁移到：仲裁条款起草、管辖异议、撤销仲裁裁决、不予执行仲裁裁决、涉港合同、建设工程和股权转让争议。

【Web补充｜更新】新修改律师法已正式施行：执业权利保障、离任从业与大湾区律师制度进入现行法

领域：律师制度 / 执业权利｜来源：全国人大常委会 / 司法部｜发布日期：2026-08-28；2026-09-01施行｜地域：全国｜内容类型：法律修改｜时效标记：本周施行

核心内容：十四届全国人大常委会第二十四次会议通过修改律师法的决定，并自2026年9月1日起施行。本次共10条修改，其中与执业直接相关的变化包括：明确有关机关和单位应建立健全律师执业权利保障制度；明确相关公职人员辞职或退休后从事律师职业或在律所工作的，应遵守公务员离职管理规定；国家积极发展涉外法律服务业；将港澳律师通过大湾区律师执业考试后在广东九市从事规定范围法律业务的制度上升至法律层面。

可直接带走的规则：从9月1日起，这些内容已经不是修正草案或政策趋势，而是现行律师法的一部分。后续涉及会见、调查取证、阅卷等执业权利保障问题时，可以直接从新法关于建立健全执业权利保障制度的规范出发；对于法官、检察官、司法行政等人员离任后进入律所的合规审查，也要同时核对公务员离职管理规则。

为什么值得我看：这是直接影响律师职业本身的法律更新，且对深圳还有额外意义：粤港澳大湾区律师执业试点被法律化。相比一般行业新闻，这一条应当作为职业基础规范长期保留。

可迁移到：律师执业权利救济、律所人员合规、涉外法律服务、粤港澳大湾区法律服务合作。

核验说明：修改决定于2026年8月28日通过并公布，2026年9月1日起施行；司法部及全国律协9月上旬连续发布权威解读。本条以正式修改决定和司法部公开解读交叉核验，未将此前二审草案表述作为最终法律内容。

【Codex评分 7.0】境外公司先注册不等于商标在先使用：在先使用抗辩仍要证明中国境内的真实使用事实

领域：知识产权 / 商标 / 证据｜来源：江门市中级人民法院｜发布日期：2026-09-04｜地域：广东｜内容类型：典型案例 / 法官实务｜时效标记：本周

核心内容：江门中院发布一起涉“杜邦”系列商标侵权二审案件，对商标在先使用抗辩的适用条件作出说明。Feed 已确认的核心争点是：境外主体成立时间较早或境外存在相关名称、标识，并不当然等于在中国大陆已经形成商标法意义上的在先使用。主张在先使用抗辩的一方仍需围绕使用时间、地域、方式、商品或服务关联以及是否已产生一定影响等事实完成证明。

可直接带走的规则：审查商标在先使用抗辩时，应把“主体存在时间”“标识形成时间”和“在中国境内实际商标性使用时间”拆开，不能相互替代。证据重点应落到中国境内销售、宣传、交易凭证、网页留痕、合同发票和相关公众认知等能证明真实使用及影响范围的材料。

为什么值得我看：虽然不是当前核心业务领域，但它的证据方法有跨案价值：很多案件都存在“某个事实很早发生”却不能证明“法律要件事实已经发生”的问题。把主体设立、权利形成、实际使用和影响范围逐层拆开，是很典型的事实核验方法。

可迁移到：商标侵权、在先使用抗辩、企业名称争议、证据链审查、事实要件拆分。

核验说明：Codex 已取得江门中院微信公众号原文直链，来源为 WeRead/微信发现通道。ChatGPT 公开 Web 未找到足够可靠的同机构官网同步全文，因此本期保留原微信链接，并明确“微信原文链接已取得，但正文内容未完成独立二次核验”；摘要仅使用 Feed 已确认的核心争点，不扩写案号、金额等未独立确认细节。
