【Web补充】律师使用AI与保密特权：关键不是“用了AI”，而是工具的数据处理与访问边界

信号级别：应用落地级｜来源：Harvey｜发布日期：2026-09-25｜国内律师参考价值：高

核心内容：Harvey首席法务官围绕律师使用AI时的 attorney-client privilege 与 work product doctrine 展开分析，核心判断是：AI并未改变保密特权的基本法律逻辑，真正影响风险的是平台是否留存、训练、人工查看或向第三方开放客户内容，以及律师是否合理控制访问范围和输出流向。文章特别提醒，Agent能跨系统行动后，权限边界、自动操作范围和人工审批节点会直接影响保密风险。

为什么值得律师看：对国内律师最有迁移价值的不是美国特权法结论，而是工具治理方法：案件材料能否上传，不能只看模型能力，要同步核对数据训练、留存、子处理商、权限、审计与跨应用动作。涉及客户证据、诉讼策略和未公开商业信息时，最好建立“允许使用的工具+允许上传的数据+必须人工确认的动作”三层门禁。

核验：Harvey官方文章可直接访问；关于美国特权制度的讨论仅作为域外治理参考，不作为中国法现行规则。

【Web补充】AI正在改变律所案件经济学：效率提升之后，计费与项目利润必须重新核算

信号级别：行业动态级｜来源：Artificial Lawyer / BigHand｜发布日期：2026-09-28｜国内律师参考价值：中

核心内容：文章讨论生成式AI对法律服务成本结构和定价逻辑的冲击：当检索、初稿、审阅等投入工时下降，仅用传统小时数衡量案件价值会越来越失真。真正需要被管理的是 matter-level economics——案件实际投入、实现率、固定费利润、AI节省的时间最终流向何处，以及不同工作环节的人工判断价值。

为什么值得律师看：即使个人律师暂不改变计费方式，也应开始记录“AI前基准耗时—AI生成—人工核验—最终完成”的全链路时间。这样才能判断AI究竟减少了成本，还是把时间从起草转移到了核验；也能为未来固定费、批量案件和团队分工提供真实数据。

核验：原文为法律科技行业评论，并非监管规则或实证研究；作为律所经营趋势信号收录。

【Web补充】最高法发布新一批提级管辖典型案例：把“疑难复杂”转化为统一裁判规则的程序工具

领域：民事诉讼程序 / 管辖 / 审判监督｜来源：最高人民法院｜发布日期：2026-09-28｜地域：全国｜内容类型：典型案例｜时效标记：本周

核心内容：最高人民法院发布《人民法院司法改革案例选编（十六）》暨提级管辖典型案例，选取广东高院、海南自由贸易港知识产权法院、成都铁路运输中院、乌鲁木齐中院提级审理的4件案例，覆盖破产重整、网络传播权等领域。其制度价值在于：对辖区内新类型、疑难复杂、裁判尺度分歧明显或具有规则形成价值的案件，通过提级审理强化上级法院直接示范，形成“提级一件、指导一片”。

可直接带走的规则：遇到同类案件裁判尺度明显分歧、具有普遍法律适用意义或基层法院处理难度高时，除常规类案检索外，应把提级管辖制度作为程序策略的一部分评估；申请或建议时应具体说明“为什么该案具有规则统一价值”，而不只是强调案情复杂或金额大。

为什么值得我看：这对二审、疑难商事案件尤其有价值。它提示律师在程序层面不仅要解决“哪个法院有管辖权”，还可以思考案件是否具备上提审级、形成统一规则的条件。

可迁移到：疑难商事诉讼、破产衍生争议、知识产权、新类型案件、裁判尺度冲突案件。

核验：最高人民法院官网原文直接核验，发布日期、案例数量和提级审理法院明确。

【Web补充】执行监督裁判提示：调解书约定的迟延履行责任与法定加倍利息原则上不能重复叠加

领域：强制执行 / 调解 / 迟延履行利息｜来源：公开裁判观点整理｜发布日期：2026-09-24｜地域：全国｜内容类型：专业文章｜时效标记：本周

核心内容：公开文章整理（2025）最高法执监374号的执行监督观点：生效民事调解书已约定不履行调解义务时承担特定迟延履行民事责任的，在义务人已经按调解书承担该责任后，权利人再主张民事诉讼法规定的迟延履行期间加倍部分债务利息，原则上不予支持。其逻辑在于避免对同一迟延履行行为作双重惩罚。

可直接带走的规则：起草执行和解或法院调解方案时，要把“协议性违约/迟延责任”和“法定加倍迟延履行利息”的关系写清楚；恢复执行前先核对生效法律文书是否已经设定不履行后的特定责任，不能机械把两套责任全部累加。

为什么值得我看：与你经常处理的恢复执行、执行和解违约高度相关。申请执行金额计算表中，迟延利息是否可叠加往往直接影响申请金额准确性。

可迁移到：恢复强制执行、执行和解、民事调解书、迟延履行利息计算。

核验：本条基于公开专业文章对最高法执行监督案件的整理；未取得最高法官方全文页面，故不将其表述为司法解释或普遍强制规则，使用时应再以裁判原文及个案文书为准。

【Web补充】建设工程入库案例补读：附条件债权债务转让未成就，原发包人付款义务不当然消灭

领域：建设工程 / 债权债务转让 / 合同责任｜来源：人民法院案例库案例的公开专业整理｜发布日期：2026-09-24｜地域：全国｜内容类型：入库案例｜时效标记：近期值得补读·90d

核心内容：公开整理的人民法院案例库案例（入库编号2023-16-2-115-007；（2021）最高法民终361号）涉及施工合同解除后，由新中标单位承接前期债权债务的安排。裁判思路强调：附条件的债权债务概括转让中，条件未成就、相关主体未有效承接的，原合同债务人的既有付款义务并不当然消灭；同时应区分一般合同责任与实际施工人突破合同相对性主张工程款的不同法律结构。

可直接带走的规则：审查“项目换主体、债务由新单位承接”类协议时，至少逐项核对：债权转让通知、债务承担是否取得债权人同意、附条件是否成就、新主体是否作出明确承诺、原主体义务是否有明确免除条款。不能仅凭“新单位接手项目”推定原债务人退出。

为什么值得我看：它同时连接建设工程、合同解除、债务承担和多主体责任，是高迁移的合同责任识别模板。

可迁移到：建设工程退场协议、项目主体更换、债务承担、债务加入、多被告责任设计。

核验：案例编号、案号与裁判要点由公开专业整理交叉确认；本周发布的是解读，基础裁判并非本周新作出，故明确标为补读。
